# Prototipo Educativo TecnoColombia

## Descripción del proyecto
Prototipo educativo de una mesa de ayuda para la gestión de servicios de soporte tecnológico, desarrollado en Odoo Helpdesk y fundamentado en las buenas prácticas de ITIL 4.

## Objetivo
Diseñar y validar una propuesta de gestión de solicitudes e incidentes tecnológicos mediante el registro, clasificación, asignación, seguimiento y atención de tickets de soporte.

## Plataforma tecnológica
- Odoo Helpdesk.
- Odoo en la nube.
- Gestión de servicios de TI basada en ITIL 4.

## Niveles de soporte
1. Nivel 1: Mesa de ayuda.
2. Nivel 2: Soporte técnico.
3. Nivel 3: Ingeniería.

## Funcionalidades del prototipo
- Registro y seguimiento de tickets.
- Clasificación de solicitudes e incidentes.
- Asignación de responsables y niveles de soporte.
- Gestión de prioridades.
- Seguimiento de acuerdos de nivel de servicio (SLA).
- Validación mediante pruebas controladas.

## Acceso al prototipo educativo
https://edu-tecnocolombia.odoo.com/odoo

## Contenido del repositorio
- `documentacion/`: documentación técnica y académica.
- `evidencias/`: capturas de pantalla del prototipo.
- `pruebas/`: matrices y resultados de validación.
- `diagramas/`: diagramas de arquitectura y flujo de atención.

## Alcance
Este repositorio tiene fines académicos y documenta el diseño, configuración, funcionamiento y validación del prototipo. No representa una copia completa de la base de datos ni del servicio alojado en Odoo.
